# DIP3.0技术规范文档

## 一、病种分组成组原理

### 1.1 DIP定义
DIP（Diagnosis-Intervention Packet，按病种分值付费）是以病种组合为付费单元，基于大数据的医保支付方式。DIP通过"主要疾病诊断+主要手术操作（+相关手术操作）"的规则组合形成病种，实现对住院病例的科学分组。

### 1.2 分组原则
- **诊断与治疗关联性**：以主要疾病诊断为基础，结合主要手术操作进行分组
- **资源消耗区分度**：能够显著区分不同病种的医疗资源消耗程度
- **病例数临界值**：达到临界值以上的病种组合归入核心病种
- **病种覆盖全面性**：以核心病种为主体，综合病种为补充，覆盖普通住院疾病

### 1.3 分组规则
```
分组顺序：
1. 排除列表对照（排除不符合入组条件的病例）
2. 先期分组（器官移植、呼吸循环支持、低出生体重儿等）
3. 并项规则下的核心病种（合并相似诊断/手术操作）
4. 相关诊断辅助细分下的核心病种
5. 基本规则下的核心病种（主要诊断+主要手术操作）
```

## 二、成组规程

### 2.1 核心病种成组

#### 2.1.1 先期分组
先期分组是指对于某些资源消耗特别高、需要单独制定支付标准的病种，不纳入基本规则分组。

**先期分组类型：**
| 类型 | 示例 |
|------|------|
| 器官移植 | 心脏移植、肝脏移植、肾脏移植、骨髓移植 |
| 呼吸循环支持 | ECMO、呼吸机治疗 |
| 低出生体重儿 | 出生体重<1500g的新生儿 |

#### 2.1.2 并项规则
对原有基本核心病种通过合并相似诊断/手术操作（并项）形成的核心病种。

**并项类型：**
- **第一类并项**：同一诊断编码下不同手术方式的合并
- **第二类并项**：相同难度、相同等级、相同目的的手术合并

#### 2.1.3 基本规则
根据"主要诊断+主要手术操作"组合形成核心病种：

```
内科诊疗病种：主要诊断（无手术操作）
手术操作病种：主要诊断 + 主要手术操作
```

### 2.2 综合病种成组
病例数未达到临界值的病种组合，纳入综合病种管理：
- 按照"主要疾病诊断+主要手术操作的具体属性"聚类
- 作为核心病种付费单元的补充

### 2.3 临界值设定
- 病例数临界值用于区分核心病种与综合病种
- 国家病种库核心病种：11,553组（3.0版）
- 地方可根据实际情况调整临界值

## 三、基层病种

### 3.1 定义
基层病种是核心病种中的一个类别，适用于基层医疗机构诊治的病种。

### 3.2 特点
- **同病同治同价**：不区分医疗机构调节系数
- **病例数较多**：在基层医疗机构常见
- **费用相对稳定**：诊疗路径明确

### 3.3 基层病种范围
| 病种类型 | 示例 |
|----------|------|
| 常见内科病种 | 上呼吸道感染、急性胃肠炎 |
| 常见外科病种 | 体表肿物切除、清创缝合 |
| 慢性病管理 | 高血压、糖尿病（稳定期） |

## 四、分值及计算

### 4.1 分值定义
病种分值反映不同病种的医疗资源消耗相对于平均医疗资源消耗的程度。分值越高，代表该病种消耗的医疗资源越多。

### 4.2 分值计算方法

#### 4.2.1 平均费用法
```
公式：RWi = (mi / M) × 1000

其中：
- RWi：第i类病种的分值
- mi：第i类病种组合的平均住院医疗费用
- M：本地所有出院病例的平均住院医疗费用
```

#### 4.2.2 基准病种费用法
```
公式：RWi = (mi / M) × 1000

其中：
- RWi：第i类病种的分值
- mi：第i类病种组合的平均住院医疗费用
- M：基准病种的平均住院医疗费用
```

**基准病种选择原则：**
- 本地普遍开展
- 临床路径明确
- 并发症与合并症少
- 诊疗技术成熟且费用相对稳定

#### 4.2.3 标准定额法
```
公式：RWi = mi / M

其中：
- RWi：第i类病种的分值
- mi：第i类病种组合的平均住院医疗费用
- M：标准定额（固定参数，相当于分值为1）
```

### 4.3 时间权重
历史费用数据按时间加权计算：
```
时间权重比例：前三年数据按 1:2:7 比例计算
例如：2023年测算 → 2020年:2021年:2022年 = 1:2:7
```

### 4.4 分值结构

#### 4.4.1 药品分值
```
公式：dRWi = (dmi / dM) × 1000

其中：
- dRWi：第i类病种的药品分值
- dmi：第i类病种组合的平均药品费用
- dM：全部住院病例平均药品费用
```

#### 4.4.2 耗材分值
```
公式：cRWi = (cmi / cM) × 1000

其中：
- cRWi：第i类病种的耗材分值
- cmi：第i类病种组合的平均耗材费用
- cM：全部住院病例平均耗材费用
```

## 五、调节系数

### 5.1 医疗机构等级调节系数

#### 5.1.1 定义
反映不同等级医疗机构在同一病种上的资源消耗差异。

#### 5.1.2 计算公式
```
医疗机构等级调节系数 = 同级别类型医疗机构某病种近三年数据病例加权平均住院费用
                       ÷ 全市该病种近三年数据病例加权平均住院费用
```

#### 5.1.3 遴选原则
1. 该病种在不同等级类型医疗机构资源消耗差异大
2. 该病种覆盖历史病例数较多，且各等级类型医疗机构病例数不低于一定阈值
3. 各等级类型医疗机构次均费用不倒挂

#### 5.1.4 特殊情况
- 保守治疗病种：仅以医疗机构类别设定系数，不以病种计算系数
- **基层病种**：不区分医疗机构调节系数，实施同病同治同价

### 5.2 辅助分型调节系数

#### 5.2.1 触发条件
1. 该病种上年度病例数超过一定例数
2. 参与某一分型评估的病例数超过一定例数
3. 采用辅助分型分组后费用差异明显改善（例如CV下降20%以上）

#### 5.2.2 触发系数计算
```
辅助分型触发系数 = 该辅助分型上年度病例平均住院费用
                  ÷ 该病种上年度平均住院费用
```

#### 5.2.3 调节系数计算
```
辅助分型调节系数 = mj / M

其中：
- mj：该病种内第j类辅助分型上年度满足触发条件病例的平均住院费用
- M：该病种上年度全部病例平均住院费用
```

#### 5.2.4 辅助分型类型

**（1）疾病严重程度辅助分型**

恶性肿瘤分型：
| 分型 | 条件 |
|------|------|
| 死亡病例 | 出院状态为死亡 |
| 高费用类型一 | 医疗费用≥3倍分值费用标准，治疗费占比≥50% |
| 高费用类型二 | 医疗费用≥3倍分值费用标准，药品费用占比≥50% |
| 肿瘤转移 | 次要诊断含恶性肿瘤，且所属类目与主要诊断不同 |
| 功能衰竭 | 次要诊断属于"功能衰竭、休克、脓毒症"范围 |
| 器官病损 | 次要诊断属于"重要器官病损、重要脏器感染"范围 |
| 其他 | 其他情况 |

非恶性肿瘤分型：
| 分型 | 条件 |
|------|------|
| 死亡病例 | 出院状态为死亡 |
| 重度 | 次要诊断属于"功能衰竭、休克、脓毒症"范围，住院天数>3天 |
| 中度 | 次要诊断属于"重要器官病损、重要脏器感染"范围，住院天数>3天 |
| 轻度 | 其他病例 |

**（2）年龄特征分型**

| 年龄段 | 分型说明 |
|--------|----------|
| 0-28天 | 新生儿期 |
| 29天-1周岁 | 婴幼儿期 |
| 1-6岁 | 学龄前期 |
| 7-17岁 | 学龄期/青春期 |
| ≥65岁 | 老年病种 |

**（3）CCI合并症/并发症分型**
- 根据CCI指数评估合并症严重程度
- 识别对费用有显著影响的合并症/并发症

**（4）ICU住院天数分型**
- 监护病房住院天数超过一定阈值
- 触发条件可适当放宽

## 六、计算公式汇总

### 6.1 分值计算
| 方法 | 公式 |
|------|------|
| 平均费用法 | RWi = (mi / M) × 1000 |
| 基准病种费用法 | RWi = (mi / M基准) × 1000 |
| 标准定额法 | RWi = mi / M标准 |
| 药品分值 | dRWi = (dmi / dM) × 1000 |
| 耗材分值 | cRWi = (cmi / cM) × 1000 |

### 6.2 调节系数
| 系数类型 | 公式 |
|----------|------|
| 医疗机构等级系数 | = 同级别某病种平均费用 ÷ 全市该病种平均费用 |
| 辅助分型触发系数 | = 该分型病例平均费用 ÷ 该病种平均费用 |
| 辅助分型调节系数 | = mj / M |

## 七、实施要点

### 7.1 数据要求
- 使用近三年历史费用数据
- 数据包括医保患者及自费病人
- 确保数据的完整性、准确性、及时性

### 7.2 分值调整原则
- 保持总分值不变
- 以病种为单位进行内部结构调整
- 统筹考虑本地和异地住院医疗费用情况

### 7.3 特殊情况处理
- 新药新技术：可对相应费用单独计算加成分值
- 中医优势病种：不纳入辅助分型范围
- 床日病种：不纳入辅助分型范围
