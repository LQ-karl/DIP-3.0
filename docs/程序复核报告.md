## 二、新增模块说明

### 2.1 数据库模块 (database/)

#### 2.1.1 数据库模型 (models.py)
支持的表结构：
- **medical_records**: 病例表 - 存储医保结算清单数据
- **disease_groups**: 病种表 - 存储DIP病种分组信息
- **dip_directory**: DIP目录表 - 存储国家DIP3.0目录库
- **disease_values**: 分值表 - 存储病种分值计算结果
- **icd10**: ICD-10编码表
- **icd9_cm3**: ICD-9-CM-3编码表
- **hospitals**: 医院表 - 存储医疗机构信息
- **hospital_coefficients**: 等级系数表 - 存储医院调节系数
- **auxiliary_classifications**: 辅助分型表 - 存储辅助目录分型信息
- **quality_check_results**: 质量控制结果表
- **operation_logs**: 操作日志表

#### 2.1.2 数据库连接器 (connector.py)
支持的数据库类型：
- SQLite
- MySQL
- SQL Server
- Oracle

### 2.2 质量控制模块 (quality_control.py)

实现的检查项：
1. **病例数不足检查**: 检查病种病例数是否达到阈值
2. **费用异常检查**: 检查费用是否超过3倍标准差
3. **编码错误检查**: 检查ICD编码是否有效
4. **病种漂移检查**: 检查病种分布变化
5. **高套分组检查**: 检查编码升级行为
6. **冲点数风险检查**: 检查费用异常低的病例

### 2.3 高低倍率处理模块 (high_low_rate_handler.py)

实现的功能：
1. **高倍率病例识别**: 费用超过平均费用2倍
2. **低倍率病例识别**: 费用低于平均费用50%
3. **极端高倍率识别**: 费用超过平均费用3倍
4. **极端低倍率识别**: 费用低于平均费用30%
5. **特殊病例识别**: 住院天数异常、费用异常等
6. **倍率统计分析**: 按病种统计高低倍率比例

### 2.4 可视化模块 (visualization/charts.py)

实现的图表：
1. **费用分布图**: 总费用、药品费用、耗材费用、住院天数分布
2. **病种分布图**: 病种病例数分布、分组类型分布
3. **分值对比图**: 病种分值vs平均费用、药品分值vs耗材分值
4. **异常病例散点图**: 费用倍率分布可视化
5. **医院对比图**: 各医院病例数、平均费用对比
