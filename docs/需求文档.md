# 医保DIP按病种分值分组测算工具 需求文档

## 1. 项目概述

### 1.1 项目背景
根据《国家医疗保障按病种分值(DIP)付费3.0版技术规范》，为实现DIP病种分组、分值计算、点值测算、支付标准制定等核心功能，开发一套完整的DIP按病种分值分组测算工具。

### 1.2 项目目标
- 实现DIP病种自动分组（核心病种+综合病种）
- 支持多种分值计算方法
- 支持调节系数设置与计算
- 支持4101A接口数据解析
- 提供模拟测算与分析报表

### 1.3 技术规范依据
- 《国家医疗保障按病种分值(DIP)付费3.0版技术规范》（主要）
- 《国家医疗保障按病种分值付费(DIP)技术规范》1.0版（补充）
- 《DIP技术规范2.0版》（补充）
- 《医疗保障信息平台定点医药机构接口规范》4101A接口

## 2. 功能需求

### 2.1 数据管理模块

#### 2.1.1 目录库管理
- **功能描述**：加载和管理DIP病种目录库（国家版3.0）
- **数据来源**：`data/低标目录(1).xlsx`、`data/新增医保手术操作代码.xlsx`等
- **核心功能**：
  - 加载ICD-10疾病诊断目录（医保版2.0）
  - 加载ICD-9-CM-3手术操作目录（医保版3.0）
  - 加载DIP核心病种目录
  - 加载DIP综合病种目录
  - 支持目录版本管理

#### 2.1.2 字典管理
- **功能描述**：管理系统字典数据
- **数据来源**：`data/`目录下的字典文件
- **核心功能**：
  - 医疗机构级别字典
  - 科室类型字典
  - 费用类型字典
  - 出院状态字典
  - 医保类型字典

#### 2.1.3 辅助目录管理
- **功能描述**：管理辅助分型相关目录
- **数据来源**：`data/辅助分型AI参考.docx`、`data/中重度分型诊断.xlsx`、`data/CCI.xlsx`
- **核心功能**：
  - CCI（Charlson合并症指数）目录
  - 疾病严重程度分型目录（轻度/中度/重度）
  - 肿瘤严重程度分型目录
  - 年龄特征分型规则

### 2.2 病种分组模块

#### 2.2.1 基础分组规则
- **功能描述**：按照"主要诊断+主要手术操作(+相关手术操作)"规则进行病种分组
- **分组逻辑**（依据3.0规范第三章）：
  ```
  1. 排除列表对照
  2. 先期分组（AA1心肺移植、AI1-AI5低出生体重儿等）
  3. 并项规则（诊断并项、手术操作并项）
  4. 相关诊断辅助细分（烧伤类、肿瘤类、结核类）
  5. 基本规则（内科诊疗病种、手术操作病种）
  ```

#### 2.2.2 核心病种分组
- **功能描述**：形成核心病种（病例数≥临界值）
- **分组规则**：
  - 内科诊疗病种：主要诊断4位码聚类
  - 手术操作病种：主要诊断4位码+主要手术操作
  - 相关操作病种：主要诊断+主要手术操作+相关手术操作（资源消耗≥10%）
- **临界值设置**：默认15例（地市级），可配置

#### 2.2.3 综合病种分组
- **功能描述**：形成综合病种（病例数<临界值）
- **分组规则**：将病例数未达到临界值的病种组合进行收敛聚类

#### 2.2.4 先期分组
- **功能描述**：处理特殊病种的先期分组
- **分组类型**：
  - AA1：心肺移植
  - AA2：心脏移植
  - AI1-AI5：低出生体重儿系列

### 2.3 分值计算模块

#### 2.3.1 平均费用法
- **计算公式**：`RWi = mi / M × 1000`
  - `mi`：第i类病种组合的平均住院医疗费用
  - `M`：本地所有出院病例的平均住院医疗费用
- **数据要求**：前三年历史数据，权重1:2:7

#### 2.3.2 基准病种费用法
- **计算公式**：`RWi = mi / M × 1000`
  - `mi`：第i类病种组合的平均住院医疗费用
  - `M`：基准病种的平均住院医疗费用（如急性阑尾炎腹腔镜切除术）

#### 2.3.3 标准定额法
- **计算公式**：`RWi = mi / M`
  - `mi`：第i类病种组合的平均住院医疗费用
  - `M`：设定的标准定额（固定参数）

#### 2.3.4 分值结构
- **药品分值**：`dRWi = dmi / dM`
- **耗材分值**：`cRWi = cmi / cM`
- **新药新技术加成**：支持HTA评估后的分值加成

### 2.4 调节系数模块

#### 2.4.1 医疗机构调节系数
- **计算方法**：
  ```
  基本系数 = 同级别类型医疗机构病例加权平均住院费用 / 全市病例加权平均住院费用
  加成系数 = f(医疗水平, 专科特色, CMI, 绩效考核, 协议履行)
  医疗机构调节系数 = 基本系数 + 加成系数
  ```

#### 2.4.2 辅助分型调节系数
- **触发条件**：
  1. 病种上年度病例数超过阈值
  2. 参与分型评估的病例数超过阈值
  3. 使用辅助分型后CV下降≥20%
- **分型类型**：
  - 恶性肿瘤疾病严重程度分型
  - 非恶性肿瘤疾病严重程度分型（死亡/重度/中度/轻度）
  - 年龄特征分型（0-28天/29天-1岁/1-6岁/7-17岁/65+）
  - 监护病房住院天数分型

### 2.5 点值计算模块

#### 2.5.1 年初点值
- **计算公式**：`年初点值 = 加权平均年度住院总费用 / 加权年度总分值`
- **计算方法**：
  - 分位数法：设置97.5%和2.5%裁剪上下限
  - 优值区间法：选择收入低、成本低的医疗机构区域

#### 2.5.2 结算点值
- **计算公式**：`结算点值 = (当年医保基金DIP付费总额 / 医保支付比例) / 当年度DIP总分值`

### 2.6 支付标准模块

#### 2.6.1 基础支付标准
- **计算公式**：`支付标准 = 病种分值 × 点值`

#### 2.6.2 特例单议
- **适用范围**：费用超过平均支付标准2倍以上的病例
- **数量限制**：不超过统筹地区DIP出院总病例的5‰

### 2.7 4101A接口数据解析模块

#### 2.7.1 接口数据结构
- **基本信息**（表201）：参保人基本信息
- **住院诊疗信息**（表202）：入院/出院信息、诊断信息
- **手术操作信息**（表203）：手术操作编码、日期、术者等
- **费用明细信息**（表203）：收费项目、金额等
- **重症监护信息**（表204）：ICU类型、进出时间

#### 2.7.2 核心字段映射
| 字段代码 | 字段名称 | 用途 |
|---------|---------|------|
| mdtrt_id | 就诊ID | 病例唯一标识 |
| main_diag_code | 主要诊断代码 | 分组依据 |
| main_diag_name | 主要诊断名称 | 分组依据 |
| oprn_oprt_code | 主要手术操作代码 | 分组依据 |
| oprn_oprt_name | 主要手术操作名称 | 分组依据 |
| real_pay_amt | 实际支付金额 | 费用计算 |
| hosp_type | 医疗机构类型 | 调节系数 |

### 2.8 模拟测算模块

#### 2.8.1 历史数据回测
- **功能**：使用历史数据模拟DIP结算
- **输出指标**：
  - 总费用、按DIP结算费用
  - 平均结付率
  - 医疗机构承担费用及比例
  - 与原支付方式差值对比

#### 2.8.2 报表输出
- **报表类型**：
  - 病种分值汇总表
  - 分值点值测算表
  - 医疗机构调节系数表
  - 模拟测算对比表
  - 费用异常病例清单

## 3. 非功能需求

### 3.1 性能要求
- 支持10万+病例数据的分组计算
- 分组计算响应时间<30秒
- 报表生成时间<60秒

### 3.2 数据要求
- 支持Excel格式数据导入
- 支持4101A接口XML/JSON数据解析
- 数据精度：金额保留2位小数，分值保留4位小数

### 3.3 安全要求
- 数据脱敏处理
- 操作日志记录
- 数据备份机制

## 5. 接口设计

### 5.1 数据导入接口
```python
# Excel数据导入
def import_disease_directory(file_path: str) -> dict
def import_cost_data(file_path: str) -> dict
def import_adjustment_coefficient(file_path: str) -> dict

# 4101A接口数据解析
def parse_4101a_data(xml_data: str) -> dict
def parse_settlement_list(data: dict) -> dict
```

### 5.2 计算接口
```python
# 病种分组
def group_diseases(case_data: list, threshold: int = 15) -> dict

# 分值计算
def calculate_disease_value(method: str, case_data: list) -> dict
def calculate_drug_value(case_data: list) -> dict
def calculate_consumable_value(case_data: list) -> dict

# 调节系数
def calculate_hospital_coefficient(hospital_data: list) -> dict
def calculate_auxiliary_coefficient(disease_code: str, case_data: list) -> dict

# 点值计算
def calculate_initial_point_value(total_cost: float, total_value: float) -> float
def calculate_settlement_point_value(fund_amount: float, payment_ratio: float, total_value: float) -> float

# 支付标准
def calculate_payment_standard(disease_value: float, point_value: float) -> float
```

### 5.3 模拟测算接口
```python
# 模拟测算
def simulate_dip_settlement(history_data: list, params: dict) -> dict

# 报表生成
def generate_value_report(results: dict) -> str

```
